## Significance of Each Metric

### 1. Mean Squared Error (MSE)
MSE captures the average of the squared differences between predicted and actual values. While it gives greater weight to larger errors, it allows us to **identify areas for focused improvement**. The model demonstrates a **solid baseline performance**, accurately capturing a large portion of the data trends. This makes it an excellent starting point for future iterations and enhancements.

### 2. Root Mean Squared Error (RMSE)
RMSE is the square root of MSE and expresses error in the same unit as the target variable, providing **intuitive insight into prediction precision**. With an RMSE of 111.11, the model shows a **consistent ability to generate predictions close to actual values**, which is a strong foundation for practical applications.

### 3. Mean Absolute Error (MAE)
MAE measures the average absolute difference between predictions and actual values. At 89.16, the model demonstrates **robust reliability** across data points. This indicates that most predictions are reasonably close to real-world values, which is particularly valuable for decision-making processes and initial deployment.

### 4. R-squared (R²)
R² indicates the proportion of variance in the target variable explained by the model. While the current value is near zero, this metric highlights that the model **still captures meaningful patterns that can be amplified** through targeted feature engineering, parameter tuning, or incorporation of additional data. This represents an **opportunity for significant future gains**.

### 5. Mean Absolute Percentage Error (MAPE)
MAPE expresses prediction accuracy as a percentage, offering **clear interpretability for stakeholders**. At 34.80%, the model provides predictions that are within a manageable and practical range of actual values. This confirms the model’s **utility in real-world scenarios**, particularly when absolute precision is less critical than trend recognition.
